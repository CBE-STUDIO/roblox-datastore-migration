DataStore Migration Guide

Move ALL your players' saved data from your old game to your new game — step by step, Windows & macOS, with copy-paste commands.

This page is one long checklist — just go down step by step. Every command has a Copy button: click it, paste into your terminal, press Enter.

How to open your terminal (you'll use this a lot)

Windows

Press the Windows key, type cmd, and press Enter — the black "Command Prompt" window opens.

macOS

Press Command (⌘) + Space, type Terminal, and press Enter.

Important for macOS: Mac uses the command python3 instead of python. Every command below shows both versions — use the one for your computer.

First, 5 words you must know

WordSimple meaning
Experience / UniverseYour whole game. It has a Universe ID (a number).
PlaceOne level inside your game. It has a Place ID.
DataStoreA cloud folder where the game saves things (coins, items...).
KeyOne entry in that folder — usually one player's data.
Open Cloud API keyA secret password that lets a script read/write your DataStores.
The big idea: DataStores do not travel between two games. Your new game starts empty. This toolkit copies everything from old to new so your players keep their progress.
1

Before you startWhat you need

  1. Your old game (full of player data) and your new game (the empty one).
  2. A computer — Windows or macOS both work.
  3. Python 3 installed — step 5 shows you how. Get it here.
  4. An Open Cloud API key — step 4 shows you how. Open the key page.
Allow about 20 minutes. Most of the time is waiting for the backup step to download your data.
2

Find your games' IDsUniverse ID & Place ID

You need four numbers total: old universe, old place, new universe, new place.

create.roblox.com → Creations
  1. Find your old game in the list and click it.
  2. Click the … (three dots) menu → choose Copy Universe ID.
  3. Paste it into Notepad / TextEdit and label it OLD UNIVERSE.
  4. For the Place ID: open your game's public page. The URL looks like roblox.com/games/123456789/My-Game. The 123456789 is the Place ID. Save it as OLD PLACE.
  5. Now do the same for your new game → save NEW UNIVERSE and NEW PLACE.
You'll paste these four numbers into config.py in step 7. Keep the note open.
3

Look at your gameFind your DataStore names

Open your old game in Roblox Studio, then:

  1. Press Ctrl + Shift + F (search across all scripts).
  2. Search for: GetDataStore
  3. Every result looks like this — the text in quotes is a name you need:
local store = DataStoreService:GetDataStore("TimeStats")

Write each name down. Real examples look like:

"ProfileStore V1", "TimeStats", "Donation", "PlayerData_v1_79229339887184"
Some names end with your old place ID (like the last example). That's normal — the toolkit automatically swaps that ending to your new place ID. Just copy the name exactly.
No Studio yet? Roblox Studio setup guide.
4

The secret passwordCreate your Open Cloud API key

Open the Credentials page
  1. Click Create API Key.
  2. Give it a name, e.g. migration.
  3. Under Access Permissions, add both experiences: your old game AND your new game.
  4. Under Permissions, enable the DataStore read and write options.
  5. Click Save & Generate Key, then copy the key.
  6. Open a text editor, paste the key on a single line, and save it somewhere easy:
Windows 
C:\Users\You\Downloads\roblox key data.txt
macOS 
/Users/You/Downloads/roblox key data.txt

Replace You with your real computer username — you'll need this exact path in step 7.

NEVER share this key. Not in Discord, not in a GitHub file, not in a screenshot. The toolkit reads it from this text file — that's the safe way.
5

One-time setupInstall Python

python.org/downloads
  1. Download the latest Python 3 for your system.
  2. Run the installer.
Windows

On the first screen, tick "Add Python to PATH", then click Install Now. This checkbox is important!

macOS

Just open the downloaded .pkg and click Continue/Install. macOS usually has Python already — the installer makes sure it's up to date.

Now open your terminal and check it installed. Click the Copy button, paste, press Enter:

Windows 
python --version
macOS 
python3 --version
If it prints something like Python 3.12.4, you're ready. On Windows, if it says "not recognized", re-run the installer and tick "Add to PATH".
6

Get the filesClone the toolkit with git

You'll download the toolkit straight into your terminal with git clone — no ZIP needed.

First, check you have Git. In your terminal, type this (works on both Windows and macOS):

git --version
If it prints a version like git version 2.45.1, you're good. If not, install it first: Download Git here (Windows: run the installer and keep the defaults. macOS: it may just work, or install via the link).

Now clone the toolkit. This one command works on Windows and macOS — click Copy, paste, Enter:

git clone https://github.com/CBE-STUDIO/roblox-datastore-migration.git

This makes a folder called roblox-datastore-migration right where your terminal is. Now go into it — the same command works on both systems:

cd roblox-datastore-migration
Windows

The folder will be created inside your user folder (e.g. C:\Users\You\roblox-datastore-migration).

macOS

The folder will be created inside your home folder (e.g. /Users/You/roblox-datastore-migration).

That's it — you now have the toolkit, and you're standing inside its folder in the terminal. Everything from here on runs with the commands in the next steps.

7

Your settingsFill in config.py

First make your own copy of the example config. In the terminal (inside the repo folder), pick your OS:

Windows 
copy scripts\config.example.py scripts\config.py
macOS 
cp scripts/config.example.py scripts/config.py

Now open scripts/config.py in Notepad (Windows) or TextEdit (macOS) and change these lines to your values from steps 2, 3 and 4:

# where your key file is (step 4)
API_KEY_FILE = r"C:\Users\You\Downloads\roblox key data.txt"

# your game numbers (step 2)
OLD_UNIVERSE = 1111111111
NEW_UNIVERSE = 2222222222
OLD_PLACE    = 111111111111
NEW_PLACE    = 222222222222

# the DataStore names you found (step 3)
STORES = [
    "ProfileStore V1",
    "TimeStats",
    "Donation",
]
macOS users: write the key path without the r and with forward slashes, e.g. "/Users/You/Downloads/roblox key data.txt".
Compare with the original config.example.py if you get stuck. Never upload config.py anywhere.
8

Run 1 of 4Back up the old game

This reads every key from your old game and saves it on your PC. It is read-only — your old game is never changed.

Windows 
python scripts\old_backup.py
macOS 
python3 scripts/old_backup.py

A folder called old_backup appears with one file per DataStore — all your players' data, safe on your computer.

Keep those backup files. They're your parachute.

9

Run 2 of 4Retry anything that failed

Sometimes a download fails (internet hiccup, Roblox rate limit). This re-tries only the failed ones:

Windows 
python scripts\retry_errors.py
macOS 
python3 scripts/retry_errors.py

Run it until it says nothing is left to retry, then continue.

Problems? (docs/09)
10

Run 3 of 4Build the migration plan

This reads your backup, fixes the place-id endings, and works out a safe merge with anything already in the new game:

Windows 
python scripts\build_ops.py
macOS 
python3 scripts/build_ops.py
  • Numbers (coins, minutes) → keep the maximum of old and new
  • Tables → merged field by field
  • Lists → combined, no duplicates
  • Nothing is ever deleted from the new game

Result: mig/ops.json. Anything ambiguous is listed in mig/conflicts.txt for you to read.

Step 10 details (docs/05)
11

Run 4 of 4Migrate!

The big one — this writes everything into your new game, 10 threads at a time:

Windows 
python scripts\migrate_oc.py
macOS 
python3 scripts/migrate_oc.py

Every write is noted in mig/applied_keys.jsonl. If it crashes, just run the same command again — it continues where it stopped.

Running it twice is safe. Keys already transferred are skipped automatically.

12

Final checkVerify in your new game

  1. Open your new game in Roblox Studio and play it.
  2. Check a few players — coins, items and time should all be there.
  3. Leaderboards need one extra step. Game passes/VIP are handled by Roblox itself.

Why this is safeThe golden rules

Old game read-onlywe only read from your old game — nothing is changed or deleted there.
Backup firsteverything is saved to your PC before a single write happens.
Merge, never wipeexisting new-game data is kept; numbers never go backwards.
Logged & resumableif it stops, run the same command again — it continues, not restarts.
Key stays secretread from a file, never in the code, blocked by .gitignore.
Rate-limit friendlyevery request retries with back-off on 429 / 5xx.
